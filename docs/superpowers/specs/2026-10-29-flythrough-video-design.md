# Пролёт: видеоролик по Pool Room

Дата: 2026-10-29. Статус: согласовано с пользователем в чате, ждёт ревью спека.

## Цель

Ролик ~50 с, в котором камера одним непрерывным пролётом показывает почти всё пространство: всплывает из бассейна, облетает первую комнату, проходит коридор с акцентом на окно и восход, влетает в луговую комнату, смотрит на столб света — и падает на пол, разбиваясь. Сверху в начале — небольшое стеклянное окно с названием и описанием.

Настроение то же, что у сцены: тихая тревога, «выхода нет», без хоррора. Всё должно выглядеть сделанным руками: никаких стоковых переходов, «вжухов», глитчей и нейросетевого слопа.

## Решения

| # | Решение |
|---|---|
| Рендер | Веб-сцена (three.js) кадр за кадром через Playwright, с выкрученным качеством. Blender не используем: на этом ПК нет RTX, а облака в Blender-версии плоские. |
| Формат | 1920×1080, 30 fps, H.264 MP4. |
| Длительность | ~50 с (≈1500 кадров). |
| Время суток | Неравномерный таймлапс 05:50 → 12:00: медленно до восхода, восход в коридоре, потом разгон до полудня. Облака плывут со своей обычной скоростью, таймлапс их не ускоряет. |
| Облака | Отдельный «видео-пресет» неба: больше шагов raymarching, крупнее и плотнее кучевые, заметнее дрейф. Интерактив не меняется. |
| Начало | Камера под водой бассейна, смотрит вверх на гладь, всплывает; на прорыве — плеск, рябь, брызги. |
| Титр | Стеклянная матовая карточка в стиле панели игры: «Pool Room» / «Две комнаты, коридор и вода. Выхода нет.» Появляется ~5 с, держится ~4 с, плавно уходит. |
| Финал | Камера зависает, смотрит вверх на столб света над лугом (пыль в луче), пауза ~2 с, затем внезапно падает, кувыркается, бьётся о кафельный бортик мелкого бассейна и ложится набок. По объективу — трещина, кадр застывает и гаснет в чёрное. |
| Звук | Только звук игры (эмбиент, вода, птицы) + плеск на всплытии + удар и хруст стекла, всё синтезом в Web Audio. После удара эмбиент глохнет, 1–2 с звучит на чёрном и обрывается. Если синтез удара звучит дёшево — предложить пользователю CC0-сэмпл с высоким рейтингом, ставить только после «да». |
| Монтаж | HyperFrames: фон — отрендеренный пролёт, поверх — титр, трещина, затемнение, звук. |

## Сценарий

| Время ролика | Камера | Время суток |
|---|---|---|
| 0–4 с | Под водой бассейна у ступеней, взгляд вверх; всплытие, прорыв глади ~3,5 с | 05:50 |
| 5–9 с | (титр поверх кадра) | |
| 4–16 с | Плавный облёт первой комнаты: бассейн сверху, луговая полоса под окном, мяч, кафель, колодцы в потолке | 05:50 → ~05:57 |
| 16–26 с | Влёт в коридор низко над водой; замедление и поворот к окну на 3–4 с — солнце выходит из-за горизонта, облака загораются | ~06:00 → 06:15 |
| 26–40 с | Выход в луговую комнату, облёт луга и мелкого бассейна; время разгоняется | 06:15 → 12:00 |
| 40–44 с | Зависание, медленный взгляд вверх на столб света из колодца | 12:00 |
| 44–46 с | Падение: короткий кувырок, удар о бортик мелкого бассейна | |
| 46–50 с | Кадр набок, трещина, затемнение, звук глохнет | |

Точные ключевые точки траектории подбираются по превью-кадрам; таблица задаёт ритм, а не координаты.

## Архитектура

Новый «видео-режим» сцены и отдельная папка `video/` с конвейером. Интерактивная версия ведёт себя как раньше.

1. **Видео-режим сцены** (`index.html?video=1`). Цикл кадров перестаёт зависеть от реального времени: страница выставляет `window.poolRoomVideo.renderFrame(i)`, который продвигает симуляцию ровно на 1/30 с и рендерит кадр. Игрок отключён, камеру ставит траектория, интерфейс скрыт, размер холста фиксирован 1920×1080. Случайности, влияющие на кадр (пыль, брызги), — от фиксированного seed, чтобы перерендер давал тот же ролик.
2. **Сценарий** (`video/shot.js`). Чистые функции времени ролика: положение и направление камеры (сплайн по ключевым точкам с плавными скоростями), время суток (кусочная кривая таймлапса), события (всплытие, удар) с их моментами. Используются и рендером кадров, и звуком — единый источник таймингов.
3. **Подводный вид.** Когда камера ниже глади бассейна: гладь видна снизу (преломлённое небо/комната и полное внутреннее отражение у краёв), поглощение и голубовато-зелёная муть с глубиной, лёгкое искажение. Нужно только для первых секунд ролика.
4. **Видео-пресет качества.** Небо: больше шагов, крупные плотные облака. Остальное — максимум того, что уже есть (полное разрешение отражений, GTAO, объёмный свет), без ограничений реалтайма.
5. **Захват кадров** (`video/render.mjs`). Playwright открывает видео-режим, по очереди вызывает `renderFrame(i)` и сохраняет кадры в `renders/frames/flythrough/f_####.png`; продолжает с места остановки, если прервать. Затем ffmpeg склеивает в `renders/flythrough_scene.mp4`.
6. **Звук** (`video/audio.mjs` + доработка `src/audio.js`). `SoundScape` научить работать на `OfflineAudioContext` с явным временем событий; по сценарию расставить плеск, звуки воды в коридоре, удар, хруст, приглушение и обрыв. Результат — `renders/flythrough.wav`.
7. **Монтаж** (`video/composition/` — проект HyperFrames). Фоновое видео, стеклянный титр, процедурная трещина (SVG/HTML, без стоковых картинок), затемнение, звук → `renders/pool_room_flythrough.mp4`.

## Проверка

- Перед полным рендером — превью: каждый 10-й кадр в половинном разрешении, просмотр ключевых моментов (всплытие, восход у окна, столб света, падение).
- Детерминизм: два рендера одного кадра совпадают.
- Итоговый ролик: длительность, 1080p/30 fps, звук синхронен с всплытием и ударом (проверка по кадрам и waveform).
- Интерактив без `?video=1` работает как прежде.
