# История проекта

Краткий пересказ всей переписки с Claude: что просили, что решили, что сделано и что дальше. Даты — 2026 год.

## 1. Идея (28 октября)

Комната в стиле pool rooms / backrooms: небольшая, с бассейном с прозрачной водой, динамическим светом и окном, под которым растёт трава с **мелкими полевыми цветами** (не большие розовые кусты).

Решения после вопросов:
- Бассейн неглубокий, максимум по пояс. Ступени постепенные, из кафельной кладки (а не металлическая лестница).
- Подсветки в бассейне и мерцающих ламп нет — только естественный свет.
- Время суток динамическое: утро, день, вечер, ночь. Цикл сначала 1,5 минуты, потом **2 минуты**, есть кнопка «Остановить время».
- Панель управления — матовое полупрозрачное стекло, скрывается клавишей H.
- Звук: атмосферный эмбиент (не удручающий), шаги по кафелю, плеск воды.
- Интерактив: один **большой разноцветный надувной мяч** у травы — толкать телом, пинать кликом, он плавает.
- Отдельный репозиторий на GitHub, изменения выгружаются автоматически.

## 2. Веб-версия и графика

- Первая версия была «слишком сырой» → переделка: кафель с фасками и швами, ступени из кладки, GTAO, объёмный свет, блум, цветокоррекция.
- Окно расширено вправо, цветы продлены под ним, за окном плывут облака.
- Глобальное освещение запекается в Blender (Cycles) для четырёх времён суток и смешивается в браузере.
- Вода: GPU-симуляция волн, каустика на дне, отражения, преломление, брызги, следы мокрых ног, трава приминается под ногами.

## 3. Blender

- Пользователь попросил подключить Blender «без мостов и переходников» и поставить всё самому — Blender 5.2 управляется напрямую из командной строки скриптом `blender/pool_room.py`.
- Видео с бликами воды: `renders/pool_room_glint.mp4`.
- По референсам (дримкор, столбы света, глянцевый кафель) сделаны финальные кадры 2560×1440: микрорельеф каждой плитки (настоящая геометрия), световые колодцы в потолке, плотная дымка, зеркальная глазурь. Кадры: полдень (2 ракурса), бассейн, вечер, ночь, день.

## 4. Свет из колодцев и пыль (29 октября)

- Колодцы перенесены и в веб-версию. Шахты сделаны мельче (0,45 м), иначе солнце не доходило до пола.
- Найдена причина «молочной» картинки: блум срабатывал на всём белом кафеле — порог поднят.
- Видимые столбы света из колодцев; 40 000 микропылинок, которые видны только в лучах; ночью над цветами кружат светлячки.

## 5. Вторая комната (29 октября)

- Проход в восточной стене ведёт в короткий коридор, залитый водой по щиколотку; одна стена коридора — окно от пола до потолка во всю длину.
- За коридором — почти такая же комната, но пол целиком луговой, а у входа — бассейн по щиколотку до самой стены (идти по воде чуть медленнее).
- Трава приминается под ногами плавно: след нарастает за долю секунды и медленно отпускает, соседние следы смешиваются.
- За окнами больше нет земли — только небо с облаками, в том числе ниже горизонта.
- Настроение: пользователь хочет не курортного спокойствия, а тихой тревоги — «выхода нет, пути назад нет», но без страшилок и без изменения музыки. Начато с цветокоррекции: чуть выцветший стерильный цвет и сужающиеся тёмные края кадра.

## 6. Инструменты

Установлено по просьбе пользователя (для будущей работы с видео и монтажом): HyperFrames, Remotion, GSAP, product-launch-motion, claude-motion-design, video-use, OpenMontage, Diffusion Studio, three.js-скиллы, taste-skill, визуальные скиллы Anthropic, MCP for Blender. Всё ставит `setup/setup.ps1`.

Правила выбора: только репозитории с большим числом звёзд; инструменты, результат которых выглядит как нейросетевой «слоп», не ставить (поэтому отклонены ComfyUI-BlenderAI-node и blender-skills с ~570 звёздами).

## Что осталось / планы

- Пройти первую настройку Diffusion Studio и выбрать Claude Code.
- Вписать ключ ElevenLabs в `video-use/.env` (если нужен монтаж по речи).
- Перерендерить финальные кадры Blender с новыми мелкими шахтами колодцев (сейчас они с шахтами 1,1 м).
- Дальше улучшать графику: пользователь просит «ещё лучше».
- По желанию — ролик-пролёт по комнате через HyperFrames.

## 7. Второй компьютер и ролик «Пролёт» (29 октября, вечер)

- Проект перенесён на второй ПК (Intel HD 630, без RTX). `setup/setup.ps1` починен: рекурсия в функции Winget, сломанный источник msstore, папка аддонов Blender для MCP.
- Интерактив отложен. Разбиение травы на куски для FPS лежит в ветке `wip/grass-chunks` (не проверено).
- Начат ролик «Пролёт»: спек `docs/superpowers/specs/2026-10-29-flythrough-video-design.md`, план `docs/superpowers/plans/2026-10-29-flythrough-video.md`, прогресс `…flythrough-video.progress.md`. Готово: сценарий камеры и таймлапса (`video/shot.js`, тесты `cd video && npm test`), детерминированный видео-режим `?video=1`, видео-пресет облаков.
- Последнее: облака переделаны в один объём на всех высотах (раньше было два слоя и пустая полоса на уровне окна) — закоммичено без просмотра. **Начать с того, чтобы посмотреть кадры 300 и 690** (`cd video && node check.mjs frame 690 out.png`), потом задача 4 — подводный вид.

## 8. Ролик «Пролёт» готов (29 октября, вечер, домашний ПК)

- Подводное начало: гладь видна снизу (окно Снеллиуса и полное внутреннее отражение), бирюзовая толща воды по пути луча, камера смотрит на ступени; на всплытии нет кадра с разрезанной поверхностью, брызги у самого объектива скрыты.
- Трава больше не чернеет на рассвете — получает отражённый свет комнаты из кубической карты.
- `video/render.mjs`: покадровый захват через `?video=1` с докачкой, превью-лист 10×15, звук офлайн (`--audio`). Полный рендер 1500 кадров — около 6 минут.
- Звук — только синтез: плеск на всплытии, тихие всплески над коридором, удар о кафель, хруст стекла, глушение и тишина к 49,5 с. Тайминги проверены по огибающей: плеск 3,514 с, удар 45,70 с.
- Монтаж в HyperFrames (`video/composition/`): стеклянный титр «Pool Room / Две комнаты, коридор и вода. Выхода нет.», процедурная трещина на объективе, затемнение. Итог — `renders/pool_room_flythrough.mp4` (1920×1080, 30 fps, 50 с, со звуком; 279 МБ, в git не лежит).
- Финальный взгляд «на столб света» перенацелен на окно в дымке: камера стояла внутри луча, и кадр засвечивался в белое.
