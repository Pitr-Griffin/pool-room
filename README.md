# Pool Room

Небольшая лиминальная комната в духе pool rooms: белый кафель, мелкий бассейн с прозрачной водой, большое окно и луговая трава с мелкими цветами, проросшая сквозь плитку под подоконником. Ламп нет, весь свет приходит из окна, а сутки проходят за полторы минуты.

**Открыть в браузере:** https://pitr-griffin.github.io/pool-room/

![Pool Room днём](docs/screenshot.jpg)

## Что внутри

- **Цикл суток за 90 секунд**: утро, день, вечер, ночь. За окном меняется небо (облака, закат, звёзды и луна), солнечный или лунный луч движется по полу и отбрасывает тень оконного переплёта.
- **Отблески воды** бегут по дну бассейна и по потолку, когда на воду падает свет.
- **Мелкий бассейн** по пояс: в него можно зайти, вода расходится кругами от шагов.
- **Луговая полоса** под окном: колышущаяся трава, ромашки, лютики, незабудки, клевер, колокольчики.
- **Надувной мяч**: его можно толкать телом, пинать кликом, он плавает в бассейне.
- **Звук** генерируется прямо в браузере: тихий светлый эмбиент, шаги по кафелю с эхом, шорох травы, плеск, птицы днём и сверчки ночью.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | ходить |
| Shift | идти быстрее |
| Мышь | осмотреться |
| Клик | пнуть мяч |
| P | пауза времени суток |
| H | скрыть панель |
| M | вкл./выкл. звук |
| Esc | вернуть курсор (чтобы двигать ползунок времени) |

Нужны клавиатура и мышь, на телефоне сцена не управляется.

## Запуск локально

Сборка не нужна: это статическая страница на [three.js](https://threejs.org/), библиотека грузится с CDN. Достаточно отдать папку любым статическим сервером, например:

```bash
npx serve .
```

## Устройство

- `src/layout.js` — размеры комнаты, бассейна, окна и луговой полосы
- `src/daycycle.js` — цикл суток: цвета неба и света, положение солнца и луны
- `src/sky.js` — небо за окном
- `src/room.js` — кафель, стены с окном, лесенка, отблески воды на поверхностях
- `src/water.js` — поверхность воды и круги на ней
- `src/meadow.js` — трава и цветы
- `src/ball.js` — мяч и его физика
- `src/player.js` — ходьба от первого лица
- `src/audio.js` — звук
- `GLOSSARY.md` — словарь понятий сцены
